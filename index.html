隐私政策

更新日期：2026年11月16日 · 生效日期：2026年11月16日

1. 我们是谁

轻贴 Daynote 由武汉智联芯创科技有限公司提供，用于管理个人便签和待办。该公司是本服务的个人信息处理者。隐私联系邮箱：wdachao@126.com。本政策适用于 iOS、macOS 及轻贴官方网站。

2. 本机使用与选择权

你可以选择“暂不登录，本机使用”，创建、编辑和完成便签，无需提供手机号。便签、待办、偏好设置默认保存在本机。登录云账号、语音识别、天气和文件导入导出均由你主动选择。拒绝可选权限不影响手动记录待办。

3. 账号与云同步

登录或注册时，我们处理手机号、安全码及随机生成的应用设备标识，用于身份校验、账号管理和跨设备同步。手机号是账号标识，不是短信验证；请勿使用他人的号码。安全码保存在系统安全存储中，服务端保存加盐校验值。启用账号后，便签标题、内容、到期日期、完成状态、标签、昵称、你选择的头像及可移植设置会同步到腾讯云广州地域的私有存储。服务端需要解密处理同步资料，因此云同步不是端到端加密。

4. 语音识别与第三方 AI

仅在你点击语音录入、阅读提示并选择“同意并开始录音”后，应用才请求麦克风权限。完成录音后，最长60秒的音频经腾讯云网关发送至阿里云百炼语音识别服务（中国地域）转换成文字；账号信息用于网关鉴权，不随音频作为识别参数发送给百炼。识别文字可编辑，确认后才加入便签。本机临时音频在识别完成、失败或取消后删除；轻贴服务端不主动保存音频文件。第三方的必要处理和留存受其服务政策约束。请勿录入未经授权的他人声音或敏感内容。不选择语音功能即可避免该项处理。

5. 天气与定位

天气默认关闭。你可手动搜索城市，城市关键词和选择地区的近似经纬度会发送至 Open-Meteo 查询天气。选择“当前位置”才请求系统定位；系统可能返回精确位置，应用将坐标降低至小数点后两位后用于地名和天气查询，不将自动定位坐标上传至轻贴云账号。Open-Meteo 是境外服务，请在同意该功能的数据传输说明后使用；也可保持天气关闭。系统地名解析由平台定位/地理编码服务处理。你可在系统设置撤销位置权限。

6. 文件、头像与共享文件夹

导入、导出和选择头像只读取你主动选择的文件，不扫描照片库或磁盘。共享文件夹功能会在你选择的目录中写入便签资料；该目录可由你使用的 iCloud、网盘或其他同步软件处理，请自行管理共享权限。导出的文件及其他设备上的副本不会因本机注销而自动删除。

7. 服务提供者

腾讯云 SCF/COS：提供账号验证、同步存储和语音转发，处理前述账号、设备标识和同步内容。阿里云百炼：仅在你同意语音功能后处理音频并返回文字。Open-Meteo：仅在使用天气时处理城市查询、近似坐标及网络请求信息。Apple/操作系统服务：用于安全存储、文件选择、系统定位与权限管理。应用不接入广告 SDK，不出售个人信息，不实施跨应用追踪，不为广告共享数据。

8. 保存期限与安全

本机资料保留至你删除、注销清空或卸载（系统备份可能另有保留）。云同步快照在账号存续期间保留，并提供最近7份历史备份；注销成功后删除账号的云资料和历史备份。服务运行日志按当前配置保留7天，主要用于安全与故障排查，不主动记录便签正文、手机号或录音。第三方网络服务可能处理 IP 地址及技术日志。传输使用 HTTPS 和额外的请求加密，存储采用访问控制；任何网络或存储措施都不能承诺绝对安全。

9. 访问、更正、撤回与注销

你可在应用内查看、编辑、删除及导出便签，在设置中修改昵称和头像、关闭天气或断开共享文件夹。注销入口：设置 → 个人 → 账号与安全 → 管理 → 注销；需输入安全码并确认。注销会删除云端账号资料并清空本机便签，操作前可先导出。网络失败时保留待完成状态并暂停同步，可重新确认。若无法登录、需撤回云服务同意或行使其他个人信息权利，请联系 wdachao@126.com；我们会核实身份后在15个工作日内回复。无需通过注销来停止本机基础功能。

10. 未成年人

本应用不面向不满14周岁儿童提供云账号服务。不满14周岁的用户请仅在监护人指导下使用本机功能，不要注册或上传个人信息。监护人发现儿童信息被提交时，可联系支持邮箱要求删除。

11. 跨境处理与政策更新

云账号和语音的主要服务地域为中国；境外用户选择这些功能意味着资料将传输到中国处理。Open-Meteo 天气及 GitHub Pages 官网托管涉及境外服务商。官网不使用广告、统计脚本或非必要 Cookie，GitHub 可能处理访问所需的技术信息。发生处理目的、范围或服务提供者的实质变化时，我们会在应用或官网更新说明，并在需要时重新征求同意。

帮助与支持

轻贴 Daynote · 更新于 2026年11月16日

1. 联系我们

技术支持与隐私请求：wdachao@126.com 请说明设备型号、系统和应用版本、复现步骤；请勿发送安全码、私人便签或其他敏感内容。

2. 不登录可以使用吗？

可以。在登录页选择“暂不登录，本机使用”，即可记录和完成待办。之后可在设置 → 个人 → 账号与安全中登录或创建云账号。

3. 多设备如何同步？

在各设备登录相同手机号和安全码，联网后自动同步。安全码由你创建，并非短信验证码。同步失败时本机内容仍保留，请检查网络和设备时间，也可先导出备份。

4. 如何关闭天气或语音权限？

天气可在设置 → 天气中关闭，也可手动选城市代替定位。麦克风仅在主动同意语音录入后使用。位置和麦克风授权都可在系统设置中撤销。

5. 如何导出、删除或注销？

设置 → 数据可导出便签资料。设置 → 个人 → 账号与安全 → 管理 → 注销可删除云账号资料并清空本机便签。请先导出需要保留的内容，并自行清理共享目录和其他设备副本。

6. 安全码遗失或登录失败

当前安全码不支持短信自助找回，请联系支持邮箱说明问题，我们将核实情况；请不要在邮件中直接发送安全码。
